# 丘丘头像工作台 v0.3.0

一个面向 SillyTavern / TauriTavern 的 **头像 + 背景工作台** UI Extension。

## v0.3.0 新增：酒馆背景工作台

工作台顶部现在可以在 **头像 / 背景** 两个页面之间切换。头像功能沿用 v0.2.3，背景页新增：

- 上传新的酒馆背景图；
- 拖拽图片调整背景显示范围；
- 缩放、水平位置、垂直位置滑杆；
- 保持原图长宽比，使用 cover 方式裁切，不拉伸背景；
- 编辑时直接在当前 SillyTavern / TauriTavern 页面中实时“试穿”背景；
- 未保存就关闭工作台或切回头像页，会恢复已经保存的背景；
- **竖屏预览（9:16） / 横屏预览（16:9）** 一键切换；
- 预览框内带轻量酒馆 UI 安全区示意，方便判断主体会不会被聊天区域遮挡。

### 背景保存范围

背景支持三个独立范围：

1. **本次聊天**：只在当前聊天使用；
2. **当前美化**：只在当前 UI 美化 / Theme 下使用，切换美化后自动切回对应背景；
3. **永久**：作为丘丘工作台的全局背景，在没有更高优先级覆盖时始终使用。

生效优先级：

```text
本次聊天 > 当前美化 > 永久 > SillyTavern 原生背景
```

因此可以同时保存：

```text
永久背景：A
像素甜点屋：B
青苹果日记：C
某个特定聊天：D
```

进入那个聊天时显示 D；离开后，像素甜点屋显示 B、青苹果日记显示 C，其他主题则显示 A。

背景文件保存在当前 WebView / 浏览器的 IndexedDB 中，不会塞进角色卡、Persona 或聊天消息正文，也不会破坏 SillyTavern 原生背景。清除 Tauri/WebView 网站数据时，背景素材也可能一并被清除。

## 头像工作台现有功能

- 每条 USER / CHAR 消息姓名后显示丘丘入口；
- 工作台图标可自定义 URL / 本地图片，图标到姓名距离可调；
- 浮动工作台可拖动、缩放；
- USER / CHAR 快速切换；
- 上传新头像、拖动构图、双指缩放；
- 水平位置 / 垂直位置 / 缩放滑杆；
- 头像固定输出 512×768（2:3），只裁切和等比例缩放，不拉伸人物；
- 当前头像框 LIVE 实时镜像预览；
- 头像预览支持竖向 / 横向排版；
- USER 支持“仅本次聊天 / 永久替换”；CHAR 仅支持永久替换；
- USER 显示保护层，兼容 AvatarDeblur 等会重写头像 DOM 的扩展；
- 收藏头像；
- 头像历史、一键回滚、单条删除、清空普通历史。

## 数据说明

头像历史、头像收藏和丘丘背景素材都保存在本机 IndexedDB。扩展设置保存背景范围、构图参数、入口图标和工作台窗口设置。

“本次聊天”背景只在当前聊天 metadata 中保存对本机背景素材的引用；因此它不会修改角色卡，也不会影响其他聊天。
