# 丘丘头像工作台

一个面向 SillyTavern / TauriTavern 的头像工作台 UI Extension。

## v0.1.5

这一版主要处理三个体验问题：

- **替换后自动刷新当前聊天**：永久头像和“仅本次聊天”头像保存成功后，会调用 SillyTavern 的 `reloadCurrentChat()` 自动重新渲染当前聊天，再重新应用聊天级头像覆盖与构图参数。无需手动退出聊天再进入；插件会尽量保持替换前的聊天滚动位置。
- **工作台 UI 重做**：菜单改成更紧凑的卡片式玻璃界面，保留原丘丘 GIF 图标；USER/CHAR、裁剪、替换范围、历史记录、入口设置分区更清楚。浮窗依旧支持拖动和从边缘/四角缩放，便于放在聊天旁观察头像框适配。
- **头像历史 / 一键回滚**：每次替换前自动备份当前头像，默认每个目标/范围保留最近 8 条。历史记录保存在浏览器 IndexedDB 中，不会塞进 Character Card、Persona 列表或聊天正文。历史卡片可一键回滚、单条删除或清空。

## 当前功能

- 每条 USER / CHAR 消息姓名后显示丘丘入口。
- 默认入口图标：`https://imgbed.heliar.top/i/hWLZsEjJm7_lklfn_IMG_1048.gif`
- 工作台图标可换 URL / 本地图片。
- 图标到姓名距离可调。
- 浮动工作台可拖动、缩小、放大。
- USER / CHAR 快速切换。
- 上传新头像、拖动构图、双指缩放。
- 水平位置 / 垂直位置 / 缩放滑杆。
- 裁剪固定输出 512×768（2:3），只裁切和等比例缩放，不拉伸人物比例。
- `保存显示范围`：只保存 X / Y / Zoom，不修改头像文件。
- `仅本次聊天`：只在当前聊天覆盖头像。
- `永久替换`：修改 Character / Persona 本体头像。
- 替换后自动刷新当前聊天，无需手动重进。
- 头像历史、一键回滚、单条删除、清空历史。

## 头像历史说明

头像历史存储在当前 WebView / 浏览器的 IndexedDB 中：

- 不会修改角色卡的历史字段；
- 不会把备份头像显示在 Persona 选择列表；
- “仅本次聊天”的历史只在对应聊天中显示；
- “永久替换”的历史跟随对应 Persona / Character；
- 每次一键回滚前，也会先把当前头像再存入历史，因此可以继续回滚回来。

清除 Tauri/WebView 网站数据或浏览器站点数据时，头像历史也可能一起被清除。

## 关于自动刷新

v0.1.5 在头像写入成功后使用 SillyTavern 的当前聊天重载接口重新渲染消息头像，并在渲染完成后再次应用聊天级头像覆盖与头像构图。这样比单纯替换 DOM 中 `<img src>` 更可靠，也能绕过部分主题、缩略图和 WebView 缓存造成的旧头像残留。
