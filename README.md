# 丘丘头像工作台 v0.3.6

一个面向 SillyTavern / TauriTavern 的 **头像 + 背景工作台** UI Extension。



## v0.3.6：USER LIVE 几何修复 + 入口图标大小

- **USER LIVE 预览拆分几何来源与样式来源**：位置、尺寸和中心点读取屏幕上真正显示的 `qqaw-protected-user-avatar`；mask、filter、opacity、object-fit 等主题视觉样式仍读取原始 `.avatar img`。这样普通 USER 不会再缩成小块，同时继续兼容复杂蒙版主题。
- **CHAR 逻辑保持简单**：CHAR 没有 USER 保护层时，几何与主题样式继续来自同一个原始头像。
- **修复 LIVE 空状态文字残影**：生成预览后强制隐藏“载入头像后……”提示，不再被某些主题 CSS 重新显示。
- **新增入口图标大小拉条**：在“工作台与入口设置”里新增 `0.60×–2.50×` 的图标缩放；它按姓名实际高度成比例放大/缩小，并与“图标到姓名距离”独立保存。

## v0.3.4：普通 USER LIVE 预览修复

- **普通头像模式恢复 v0.3.0 的完整消息骨架**：保留 `.mes::before` / `.mes::after`，因此依赖消息伪元素绘制头像框、头图或背景装饰的普通美化可以再次正常预览。
- **仍然不显示正文**：正文、姓名、楼层、tokens、用时、编辑按钮、翻页按钮等单独隐藏，不再通过隐藏整条消息来“顺带”去掉文字。
- **USER 与 CHAR 使用同一套主题几何基准**：LIVE 预览优先读取原始 `.avatar img` 的尺寸和主题样式；USER 的保护头像只负责最终聊天显示，不再参与主题预览尺寸计算。
- **蒙版头像模式保持不变**：继续只抽取 `.avatar` 容器，适合 mask、clip-path、旋转和 `.avatar::after` 装饰。

## v0.3.3：精简 LIVE 预览 + Studio UI

本版主要优化工作台本身的使用体验，不改变已经稳定的头像替换与背景逻辑。

- 当前头像框 LIVE 预览不再克隆整条消息，只读取同类型消息的 `.avatar` 头像容器；
- 不再把消息正文、姓名、楼层 / tokens / 用时、操作按钮带进预览；
- 保留头像自身的 mask、clip-path、transform、filter、透明度与 `.avatar::after` 装饰，因此复杂主题头像框仍能真实预览；
- 工作台整体升级为更整洁的 pastel studio 视觉：模式切换、卡片层级、标题、按钮、滑杆、收藏与历史区域统一；
- 对工作台内部 `.menu_button` 和 range 样式加强隔离，减少当前酒馆美化 CSS 对插件面板外观的干扰。

## v0.3.1：复杂主题头像框兼容修复

本版重点修复开启丘丘头像工作台后，部分带 **mask / 旋转 / 跟随装饰 / 自定义 z-index** 的美化主题中 USER 头像消失的问题。

- USER 保护头像不再作为 `.mes` 的独立悬浮层，而是迁入原本的 `.avatar` 容器；
- 保护头像会复用主题对 `.mes .avatar img` 的定位体系；
- 同步原头像的 `left / top / width / height / transform / z-index / mask / clip-path / opacity / filter / object-fit` 等视觉属性；
- 支持 CSS individual transforms（`translate / rotate / scale`）与 WebKit mask 属性；
- 切换主题时会先清理保护层上一套主题遗留的内联几何，再读取当前主题样式；
- 自动迁移 v0.2.1–v0.3.0 已经存在于 `.mes` 外层的旧保护头像节点；
- 原始 `<img>` 仍保留在 DOM 中供 SillyTavern / AvatarDeblur 更新，只隐藏原图显示，因此不会破坏其数据刷新逻辑。

这类主题原本常见的层级可以继续保持为：

```text
头像 / 丘丘保护头像   z-index: 2
头像装饰              z-index: 3
```

因此像「电子胸花_莓事啦兔🐰」这种用 mask 和跟随装饰构成头像框的主题，不需要为了丘丘工作台额外修改自己的 CSS。

## v0.3.0 新增：酒馆背景工作台

工作台顶部现在可以在 **头像 / 背景** 两个页面之间切换。头像功能沿用 v0.2.3，背景页新增：

- 上传新的酒馆背景图；
- 拖拽图片调整背景显示范围；
- 缩放、水平位置、垂直位置滑杆；
- 保持原图长宽比，使用 cover 方式裁切，不拉伸背景；
- 编辑时直接在当前 SillyTavern / TauriTavern 页面中实时“试穿”背景；
- 未保存就关闭工作台或切回头像页，会恢复已经保存的背景；
- **竖屏预览（9:16） / 横屏预览（16:9）** 一键切换；
- 预览框内带轻量酒馆 UI 安全区示意，方便判断主体会不会被聊天区域遮挡。

### 背景保存范围

背景支持三个独立范围：

1. **本次聊天**：只在当前聊天使用；
2. **当前美化**：只在当前 UI 美化 / Theme 下使用，切换美化后自动切回对应背景；
3. **永久**：作为丘丘工作台的全局背景，在没有更高优先级覆盖时始终使用。

生效优先级：

```text
本次聊天 > 当前美化 > 永久 > SillyTavern 原生背景
```

因此可以同时保存：

```text
永久背景：A
像素甜点屋：B
青苹果日记：C
某个特定聊天：D
```

进入那个聊天时显示 D；离开后，像素甜点屋显示 B、青苹果日记显示 C，其他主题则显示 A。

背景文件保存在当前 WebView / 浏览器的 IndexedDB 中，不会塞进角色卡、Persona 或聊天消息正文，也不会破坏 SillyTavern 原生背景。清除 Tauri/WebView 网站数据时，背景素材也可能一并被清除。

## 头像工作台现有功能

- 每条 USER / CHAR 消息姓名后显示丘丘入口；
- 工作台图标可自定义 URL / 本地图片，姓名旁入口图标大小与图标到姓名距离均可调；
- 浮动工作台可拖动、缩放；
- USER / CHAR 快速切换；
- 上传新头像、拖动构图、双指缩放；
- 水平位置 / 垂直位置 / 缩放滑杆；
- 头像固定输出 512×768（2:3），只裁切和等比例缩放，不拉伸人物；
- 当前头像框 LIVE 实时镜像预览；
- 头像预览支持竖向 / 横向排版；
- USER 支持“仅本次聊天 / 永久替换”；CHAR 仅支持永久替换；
- USER 显示保护层，兼容 AvatarDeblur 等会重写头像 DOM 的扩展；
- 收藏头像；
- 头像历史、一键回滚、单条删除、清空普通历史。

## 数据说明

头像历史、头像收藏和丘丘背景素材都保存在本机 IndexedDB。扩展设置保存背景范围、构图参数、入口图标和工作台窗口设置。

“本次聊天”背景只在当前聊天 metadata 中保存对本机背景素材的引用；因此它不会修改角色卡，也不会影响其他聊天。


## v0.3.3：普通 / 蒙版双预览入口

LIVE 头像框预览新增两个独立模式，并按当前美化主题记忆选择：

- **普通头像**：保留原消息完整 DOM 布局骨架，仅把正文、姓名、三元素、按钮等设为不可见；适合不带蒙版、依赖 flex/grid 或祖先结构定位的普通美化。
- **蒙版头像**：只镜像 `.avatar` 容器，适合使用 `mask`、`clip-path`、旋转和 `.avatar::after` 头像装饰的复杂美化。

两种模式都不会在预览里显示正文文字。切换美化后，插件会自动恢复该美化上次使用的预览类型。
