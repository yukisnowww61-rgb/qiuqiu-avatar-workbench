# 丘丘头像工作台

一个面向 SillyTavern / TauriTavern 的前端 UI Extension，用于快速处理聊天中的 USER（Persona）和 CHAR（Character）头像。

## v0.1.4

这一版重点加入三项：

1. **姓名距离真正按“文字末尾”计算**
   - 不再用 `.name_text` 元素盒子的右边缘，而是用 `Range.getClientRects()` 测量姓名文字实际显示范围。
   - “图标到姓名距离”现在范围为 `-24 px ~ 60 px`，拖动时立即重新定位。
   - 对绝对定位、transform、宽容器姓名美化更友好。

2. **工作台变成可移动、可缩放的浮动窗口**
   - 拖动顶部标题栏：移动工作台。
   - 拖动任意边缘 / 四角：调整工作台大小。
   - 右下角有可见的缩放提示角。
   - 工作台不再使用黑色全屏遮罩，也不会锁住聊天滚动；可以把窗口缩到一边，一边看聊天里的头像框一边调头像。
   - 左上/顶部的 `↙` 按钮可以恢复默认窗口大小与位置。
   - 窗口大小与位置会保存到扩展设置。

3. **头像替换支持“仅本次聊天 / 永久替换”**
   - `仅本次聊天`：把临时头像绑定写入当前聊天的 `chatMetadata`，不会修改 Character / Persona 本体；切到其他聊天仍是原头像。
   - `永久替换`：继续修改 Character / Persona 的真实头像文件，其他聊天也使用新头像。
   - 当前聊天已经有临时头像时，会出现 `取消本次聊天覆盖` 按钮，可一键恢复永久头像。

## 已实现功能

- 每条 USER / CHAR 消息姓名后显示丘丘工作台入口。
- 默认入口图标：`https://imgbed.heliar.top/i/hWLZsEjJm7_lklfn_IMG_1048.gif`
- 点击哪条消息，就优先识别那条消息对应的 Persona / Character。
- USER / CHAR 快速切换。
- 选择本地新图片。
- 拖动调整裁剪位置。
- 水平位置 / 垂直位置 / 缩放滑杆。
- 手机双指缩放。
- `保存显示范围`：不修改头像文件，只保存 X / Y / Zoom。
- `裁剪并替换头像`：固定输出 512×768 PNG，只裁切和等比缩放，不拉伸原图。
- 替换后即时刷新当前聊天头像。
- 工作台窗口可移动、可调整大小。
- 工作台图标支持 URL、本地图片、恢复默认。
- 图标与姓名间距可实时调整。
- Character 构图参数优先写入 `data.extensions.qiuqiu_avatar_workbench`，并保留扩展本地设置后备。
- Persona 构图参数保存在扩展设置。
- 扩展设置页提供备用“打开工作台”按钮。

## 使用

1. 打开聊天，点击 USER / CHAR 姓名后的丘丘图标。
2. 如需观察聊天中的头像框，可拖动标题栏把工作台移到旁边，再拖动边缘或右下角缩小窗口。
3. 选择新图片，拖动画面或调 X / Y / Zoom。
4. 选择替换范围：
   - `仅本次聊天`：只影响当前聊天；
   - `永久替换`：修改 Character / Persona 本体。
5. 点击 `裁剪并替换`。
6. “工作台图标设置”里可实时调整图标到姓名的距离。

## 关于“仅本次聊天”

临时头像的绑定记录保存在当前聊天的 `chatMetadata` 中。图片本身使用 SillyTavern 已有的头像上传接口保存，并以 `__qqaw_chat_...` 作为内部文件名。插件会在进入这个聊天和新消息出现时自动重新应用临时头像。

## 关于裁剪

最终输出固定为 `512 × 768（2:3）`。原图不会被横向压扁或纵向拉长；如果原图与裁剪比例相同且缩放为 `1.00×`，某一方向可能没有移动余量，把缩放提高到 `1.05×` / `1.10×` 即可。

## 注意

- 裁剪后的头像是静态 PNG；原头像若为 GIF，替换后不会保留动画。
- 某些主题如果强制覆盖头像的 `object-fit` / `object-position` / `clip-path`，非破坏式“保存显示范围”仍可能需要单独适配。
- 群聊建议从目标角色自己的消息后打开工作台。
- 本地图标会以 Data URL 保存到扩展设置，不建议使用特别大的本地 GIF。
