# 丘丘头像工作台 v0.2.3

一个面向 SillyTavern / TauriTavern 的头像工作台 UI Extension。

## v0.2.3 新增

### 1. 当前头像框实时预览

工作台裁剪区下方新增 **当前头像框预览（LIVE）**：

- 自动寻找当前聊天中与目标同类型的 USER / CHAR 消息；
- 镜像那条消息真实的头像位置、尺寸、透明度、滤镜、圆角、clip / mask；
- 保留当前主题对 `.mes` / `.avatar` 的装饰层，因此能观察头像放进当前美化后的实际构图关系；
- 上方拖动、缩放、调整 X / Y 时，头像框预览会实时同步；
- 预览只存在于工作台内，不会临时改写聊天消息，因此不会干扰 v0.2.1 已稳定的 USER 头像显示保护层。

如果当前聊天没有同类型消息，会显示提示而不是虚构一个头像框。

### 2. 收藏头像与历史记录分开

新增独立 **收藏头像** 区：

- 历史卡片右上角可点 `♡ / ♥` 收藏或取消收藏；
- 可以直接点 **♡ 收藏当前** 把正在使用的头像加入收藏；
- 收藏头像不会占用“最近 8 条历史”的数量，也不会被自动淘汰；
- “清空历史”只清理普通历史，不会删除收藏；
- 收藏仍然支持 **一键回滚** 和单条删除；
- 从“仅本次聊天”历史收藏的头像，也可以在同一 Persona 的其他聊天中看到；回滚时会按它原来的范围应用为本次聊天头像。

头像收藏和历史仍保存在当前 WebView / 浏览器的 IndexedDB 中。

## 当前功能

- 每条 USER / CHAR 消息姓名后显示丘丘入口。
- 默认入口图标：`https://imgbed.heliar.top/i/hWLZsEjJm7_lklfn_IMG_1048.gif`
- 工作台图标可换 URL / 本地图片。
- 图标到姓名距离可调。
- 浮动工作台可拖动、缩小、放大。
- USER / CHAR 快速切换。
- 上传新头像、拖动构图、双指缩放。
- 水平位置 / 垂直位置 / 缩放滑杆。
- 裁剪固定输出 512×768（2:3），只裁切和等比例缩放，不拉伸人物比例。
- 当前主题 / 头像框实时镜像预览。
- `保存显示范围`：只保存 X / Y / Zoom，不修改头像文件。
- `仅本次聊天`：仅 USER 可用，只覆盖当前聊天；CHAR 只支持永久替换。
- `永久替换`：修改 Character / Persona 本体头像。
- USER 聊天显示保护层，兼容后台头像重写 / AvatarDeblur 类扩展。
- 收藏头像。
- 头像历史、一键回滚、单条删除、清空普通历史。

## USER「仅本次聊天」

- 仅 USER 支持；CHAR 只提供永久替换。
- 当前聊天开启临时 USER 头像后，当前聊天优先显示临时头像。
- 取消覆盖后恢复永久 Persona 头像。
- 工作台使用独立 USER 显示保护层，避免 SillyTavern / 其他头像扩展稍后重新写入原 `.avatar img` 时造成头像回跳。

## 收藏与历史说明

头像历史 / 收藏存储在当前 WebView / 浏览器的 IndexedDB 中：

- 不会修改角色卡的历史字段；
- 不会把备份头像显示在 Persona 选择列表；
- 普通历史每个范围保留最近 8 条；
- 收藏记录不受 8 条上限影响；
- 清空历史不会清空收藏；
- 每次一键回滚前仍会先保存当前头像，因此可以继续回滚回来。

清除 Tauri/WebView 网站数据或浏览器站点数据时，头像历史和收藏也可能一起被清除。

## v0.2.3 新增：实时预览排版切换

工作台的头像调整区现在提供两种实时预览排版：

- **竖向**：保持原来的排版，裁剪/调整预览在上，当前头像框 LIVE 预览在下。
- **横向**：裁剪/调整预览在左，当前头像框 LIVE 预览在右，适合把工作台拉宽后一边调一边对照。

排版选择会自动保存，下次打开工作台继续使用上一次的选择。
