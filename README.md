# 丘丘头像工作台

一个面向 SillyTavern / TauriTavern 的头像工作台 UI Extension。

## v0.2.0

这一版重做了 **USER「仅本次聊天」头像的生效方式**，重点修复：

- 临时头像设置后，消息气泡仍反复跳回旧头像；
- Persona 设置页已经显示新头像，但当前聊天仍被旧的临时头像“锁住”；
- 重新进入聊天后头像短暂正确，随后又被改回；
- 从临时头像改成永久头像后，当前聊天仍继续显示旧临时头像。

### 这次的核心变化

1. **不再只和 DOM 的 `<img src>` 对抗。**
   当前聊天的 USER 临时头像会直接写入 SillyTavern 当前聊天消息的 `force_avatar`，然后保存聊天。重新渲染、重新进入聊天时，SillyTavern 自己就会从消息数据中读取正确头像。

2. **永久替换 / 取消临时覆盖时同步恢复消息数据。**
   当前聊天里属于这个 Persona 的 USER 消息会重新指向永久 Persona 头像，不再被旧临时记录挡住。

3. **新发送的 USER 消息会自动继承当前聊天临时头像。**
   临时头像开启期间继续聊天，新消息不需要等待额外 DOM 修补。

4. **升级到 v0.2.0 会一次性清理 v0.1.4–v0.1.8 的旧临时覆盖状态。**
   这是为了清除可能已经卡住的旧兔子头像 / 旧缓存。升级后如果还想使用“仅本次聊天”，请重新设置一次临时头像。

5. **旧状态清理后会主动重载一次当前聊天。**
   这样升级完成后，当前消息区应直接回到真正的永久 Persona 头像，而不是继续残留旧 DOM。

## 当前功能

- 每条 USER / CHAR 消息姓名后显示丘丘入口。
- 默认入口图标：`https://imgbed.heliar.top/i/hWLZsEjJm7_lklfn_IMG_1048.gif`
- 工作台图标可换 URL / 本地图片。
- 图标到姓名距离可调。
- 浮动工作台可拖动、缩小、放大。
- USER / CHAR 快速切换。
- 上传新头像、拖动构图、双指缩放。
- 水平位置 / 垂直位置 / 缩放滑杆。
- 裁剪固定输出 512×768（2:3），只裁切和等比例缩放，不拉伸人物比例。
- `保存显示范围`：只保存 X / Y / Zoom，不修改头像文件。
- `仅本次聊天`：仅 USER 可用，只覆盖当前聊天；CHAR 只支持永久替换。
- `永久替换`：修改 Character / Persona 本体头像。
- 头像历史、一键回滚、单条删除、清空历史。

## 「仅本次聊天」与永久头像

当某个聊天已经启用 USER 临时头像时：

- 当前聊天优先显示临时头像；
- 你在 SillyTavern 原生 Persona 设置页修改永久头像，不会自动取消当前聊天的临时覆盖；
- 想恢复永久头像，请在丘丘头像工作台中点击 **取消本次聊天覆盖**，或者直接选择 **永久替换**。

这属于“本次聊天覆盖”的正常优先级，而不是头像缓存错误。

## 头像历史说明

头像历史存储在当前 WebView / 浏览器的 IndexedDB 中：

- 不会修改角色卡的历史字段；
- 不会把备份头像显示在 Persona 选择列表；
- “仅本次聊天”的历史只在对应聊天中显示；
- “永久替换”的历史跟随对应 Persona / Character；
- 每次一键回滚前，也会先把当前头像再存入历史，因此可以继续回滚回来。

清除 Tauri/WebView 网站数据或浏览器站点数据时，头像历史也可能一起被清除。


## v0.2.0 USER 头像修复

- “仅本次聊天”现在是**整段聊天级 USER 覆盖**，不再按历史 Persona 文件逐条匹配。
- 当前聊天中所有 USER 消息都会统一显示临时头像；新发送的 USER 消息也会自动继承。
- 取消临时覆盖时，会逐条恢复各消息在覆盖前自己的 `force_avatar`，因此不会破坏历史 Persona 信息。
- USER 工作台始终以当前实际选中的 Persona 为永久编辑目标，不再从旧消息头像猜测当前 Persona。
- USER 永久替换后，会同步当前聊天所有 USER 消息到新的永久头像，避免旧 Persona 图片继续残留在气泡里。
