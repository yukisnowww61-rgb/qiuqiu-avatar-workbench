# 丘丘头像工作台

一个面向 SillyTavern / TauriTavern 的前端 UI Extension，用于快速处理聊天中的 USER（Persona）和 CHAR（Character）头像。

## v0.1.3

这一版重点修复三个实际使用问题：

1. **姓名后入口真正绑定到每条消息**
   - 工作台图标改为挂在对应 `.mes` 消息内部，不再使用 `position: fixed`。
   - 滚动聊天时，图标会跟着自己的那条消息一起移动，不会悬浮停留在屏幕上。
   - “工作台图标设置”增加 **图标到姓名距离** 滑杆，可在 `-8 px ~ 40 px` 间调整。

2. **裁剪不再拉伸人物比例**
   - 裁剪预览改为 Canvas，水平位置 / 垂直位置 / 缩放与最终导出使用同一套裁剪算法。
   - 最终头像固定输出 `512 × 768（2:3）`。
   - 原图只会被裁切和等比例缩放，不会横向拉宽或纵向拉长。
   - 如果当前缩放下某个方向没有可移动余量，工作台会提示先稍微放大再移动。

3. **替换头像后即时刷新当前聊天**
   - 上传成功后直接给当前聊天中的对应 Persona / Character 头像换成带缓存破坏参数的新地址。
   - 同时监听/触发 SillyTavern 的 Persona / Character 更新事件，并做多次短延迟刷新，尽量避免主题或 ST 自己重新写回旧缩略图。
   - 正常情况下不再需要退出并重新打开聊天。

## 已实现功能

- 每条 USER / CHAR 消息姓名后显示丘丘工作台入口。
- 默认入口图标：`https://imgbed.heliar.top/i/hWLZsEjJm7_lklfn_IMG_1048.gif`
- 点击哪条消息，就优先识别那条消息对应的 Persona / Character。
- USER / CHAR 快速切换。
- 选择本地新图片。
- 拖动调整位置。
- 水平位置 / 垂直位置 / 缩放滑杆。
- 手机双指缩放。
- `保存显示范围`：不修改头像文件，只保存 X / Y / Zoom。
- `裁剪并替换头像`：输出 512×768 PNG 并覆盖当前头像。
- Character 构图参数优先尝试写入 `data.extensions.qiuqiu_avatar_workbench`，并保留扩展本地设置后备。
- Persona 构图参数保存在扩展设置。
- 工作台图标支持 URL、本地图片、恢复默认。
- 图标与姓名间距可在工作台中实时调整。
- 扩展设置页提供备用“打开工作台”按钮。

## 使用

1. 打开聊天。
2. 点击 USER 或 CHAR 姓名后的丘丘图标。
3. 选择新图片，或载入当前头像。
4. 拖动画面，或者使用“水平位置 / 垂直位置 / 缩放”。
5. 选择：
   - `保存显示范围`：不修改原图；
   - `裁剪并替换头像`：真正覆盖头像文件。
6. 展开“工作台图标设置”可调整图标和姓名之间的距离。

## 关于水平移动

工作台不会通过拉伸图片制造移动空间。如果一张图片本身刚好与 2:3 裁剪框完全一致，且缩放为 `1.00×`，横向或纵向可能没有多余像素可移动。这时把缩放稍微提高，例如 `1.05×` 或 `1.10×`，即可产生可移动裁剪余量。

## 注意

- 裁剪后的头像是静态 PNG；原头像若为 GIF，替换后不会保留动画。
- 某些高度自定义主题如果强制覆盖头像的 `object-fit` / `object-position` / `clip-path`，非破坏式“保存显示范围”仍可能需要单独主题适配。
- 群聊里建议从目标角色自己的消息后打开工作台，以便准确识别 Character。
- 本地图标会以 Data URL 保存到扩展设置中，不建议使用特别大的本地 GIF。
